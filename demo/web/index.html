About this debugger
The unchanged authors’ JSFlow interpreter (2021 commit) runs in a Web Worker. Step advances its real work list to the next statement; breakpoints pause before that statement executes, including on repeated loop iterations. The variables and hover data come from the current JSFlow environment. Object previews read internal data descriptors and do not invoke getters. This is a teaching adapter, not a reproduction of the 2016 paper’s evaluation.
publicOutput(value) is our public sink: it rejects secret values or a secret execution context. print(value) is trusted diagnostic output. The interpreter supports non-strict ES5; browser DOM, network and Node modules are unavailable to interpreted programs. The server serves static files only. The examples define defer inline using a random delay and setTimeout. A limited timer host adapter waits in real time, then resumes interpreted callbacks while preserving argument labels and the scheduling context. Delays are clamped to 0–2000 ms, callbacks are limited to functions, and cancellation is not provided. Promises and async/await are not provided. Long runs can be stopped; workers have execution and output limits. Some synchronous built-in calls cannot pause internally.
